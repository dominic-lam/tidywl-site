What TidyWL for Netflix is, and what it is not

TidyWL for Netflix is a Chrome extension that opens a dashboard over Netflix for managing your own My List and your own playlists: search, filter, sort, bulk remove, custom playlists, export. It runs in your browser, with the Netflix session you are already signed in to, and it calls the same web endpoints Netflix's own page calls. Netflix has no public API for My List, so there is no official route to use instead.

That design is what makes it work, and it is also the honest caveat: Netflix did not build those endpoints for us and can change or close them without notice. The extension reads a remote configuration so that many Netflix-side changes can be fixed without a new version, and we update the extension when they cannot. We do not promise that any feature will keep working, and these terms say what happens when one does not (see If Netflix changes below).

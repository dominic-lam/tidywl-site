What TidyWL is, and what it is not

TidyWL is a browser extension that opens a dashboard on YouTube for managing your own Watch Later, Liked videos and playlists: search, filter, sort, bulk delete, reorder, move, export. It runs in your browser, with the YouTube session you are already signed in to, and it calls the same web endpoints YouTube's own page calls. It does not use YouTube's official Data API, because that API does not allow access to Watch Later.

That design is what makes TidyWL work, and it is also the honest caveat: YouTube did not build those endpoints for us and can change or close them without notice. TidyWL ships a remote configuration layer so that many YouTube-side changes can be fixed without a new extension version, and we update the extension when they cannot. We do not promise that any feature will keep working, and these terms say what happens when one does not (see If YouTube changes below).
